 HTML Advanced – Semantic Structure Project

##  Project Description 
This project is part of the ALU Web Development curriculum.   
The goal is to recreate a webpage structure from a Figma design using pure HTML, without any CSS or styling. 

The focus is on:
- Correct HTML5 semantic structure
- Clean and readable markup
- Proper use of headings, sections, and containers
- Preparing a strong foundation for future styling

 

#  Objectives 
- Understand and apply semantic HTML
- Translate a designer file (Figma) into HTML structure 
- Use appropriate tags such as:
  - `<header>`
  - `<main>`
  - `<section>`
  - `<div>`
  - `<h1>`–`<h3>`
  - `<p>`, `<img>`, `<a>`, `<button>`, `<blockquote>`
